# Consultas SQL sobre una base de ventas

Proyecto de demostración: crea una base de datos SQLite de ventas con Python y responde preguntas de negocio con consultas SQL.

## Qué hace

- Crea una base de datos (`ventas.db`) con una tabla de ventas
- Carga datos de ejemplo
- Ejecuta 5 consultas SQL: total vendido, promedio por venta, total por cliente, ranking de productos y ventas mayores a 10.000

## Resultados de ejemplo

- Total vendido: 99401.0
- Promedio por venta: 16566.83
- Producto que más facturó: Monitor (90000.0)
- Mejores clientes: Luis Diaz y Sofia Lopez (45000.0 cada uno)

## Cómo usarlo

1. Crear la base de datos: `py crear_base.py`
2. Ejecutar las consultas: `py consultas.py`

## Conceptos aplicados

SELECT, SUM, AVG, COUNT, GROUP BY, ORDER BY, WHERE

## Tecnologías

Python, SQLite, SQL
